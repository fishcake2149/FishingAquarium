# v2 통합 프로토타입 구현 상태

## 완료된 핵심

- 16:9 기본 화면과 반응형 HUD
- WASD 자유 이동 + 좌클릭 상호작용
- Grid 기반 월드 오브젝트 / NPC A* 경로 탐색
- 플레이어 추적 및 맵 경계 카메라 클램프
- 연못 수심을 항상 보이는 얕은/중간/깊은 3단계 물색으로 표현
- 왕복 캐스팅 게이지와 실제 찌 착수 수심 판정
- 연못 생물 14종의 수심/날씨/시간 출현 필터 (비단잉어 제외)
- 기존 핵심 조작을 반영한 360도 낚시 + 현재 월드 Blur/Dim 오버레이
- 생물 종별 스택 9칸 인벤토리와 도감 크기 기록
- 낚싯대/찌/미끼/액티브 장비 구조
- 시간, 날씨, 그림자/조명, 야간 생물
- 상점/판매/수조 전시/방문객/일일 정산
- 관리자실 전용 잠자기 및 입장료 변경
- localStorage v2 저장과 일부 기존 데이터 마이그레이션

## 회귀 안전장치

대규모 개편 직전 main 상태는 `backup/pre-refactor-20260915` 브랜치에 보존했습니다. 기존 단일 HTML 프로토타입도 삭제하지 않았습니다.

## 검증

- `game-source.js` JavaScript 문법 검사 통과
- DOM/canvas mock 런타임 부팅 검사 통과
- 생물 출현 조건, 종별 스택, 도감 최소/최대 기록, 관리자실 접근성 등 핵심 로직 검사 통과
- 고주사율 의존을 막기 위한 fixed timestep 유지

실제 브라우저 화면 캡처 자동 검증은 작업 환경의 headless Chromium 실행 문제로 완료하지 못했으므로, Pages 활성화 후 실제 화면에서 한 번 더 확인합니다.

## GitHub Pages

자동 배포 워크플로는 `.github/workflows/pages.yml`에 준비되어 있습니다. GitHub Actions 토큰은 아직 생성되지 않은 Pages 사이트를 최초 생성할 권한이 없어 첫 실행이 `Configure Pages` 단계에서 중단되었습니다. 저장소 `Settings → Pages`에서 Build and deployment Source를 `GitHub Actions`로 한 번 활성화하면 이후 같은 주소로 자동 배포되도록 구성했습니다.
